# Obsidian

## Verified behavior

PDF highlights dragged directly from Zotero can be rendered as Markdown callouts with:

- a `PDF Highlight · Page N` title;
- the full highlight text;
- a single `Open PDF` link retaining the Zotero item, page and annotation identifiers;
- the citation text generated by Zotero.

This behavior is supplied by the [Zotero Drop Callout](https://github.com/NanXiudao/zotero-drop-callout) plugin.

## Callout example

```markdown
> [!quote] PDF Highlight · Page 3
>
> In RBO, we test the optimization performance...
>
> [📄 Open PDF](zotero://open-pdf/library/items/HGACVREL?page=3&annotation=L5RV6EX5) · (Tom 等, 2025, p. 3)
```

The link is an example and requires Zotero to handle the `zotero://` protocol.

## Recommended safety checks

- Use a test note before changing templates or plugin versions.
- Keep a backup of your Obsidian vault and `.obsidian` settings.
- Do not publish private notes, literature databases or synced vault credentials.
