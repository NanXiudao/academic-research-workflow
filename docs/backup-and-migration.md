# 配置备份与迁移

1. 备份 Obsidian 仓库，尤其是 `.obsidian/plugins` 和 `.obsidian/snippets`。
2. 复制 Zotero 高级设置中的原生高亮模板内容。
3. 备份 Zotero 用户配置目录的 `chrome/userChrome.css`。
4. 记录 `toolkit.legacyUserProfileCustomizations.stylesheets=true`。
5. 备份 ZotLit Template Workbench 中的**笔记**和**标注**模板。
6. 导出 Zotero Style 的自定义列配置，记录插件版本。
7. 新设备上安装 Zotero 和 Obsidian，恢复设置。
8. 拖入一条 PDF 高亮，确认页码、引用与 Open PDF 定位正常。

不要将私人文献数据库、未公开笔记、同步密码或 API Token 上传到公开仓库。
