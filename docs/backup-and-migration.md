# Backup and migration checklist

1. Back up the Obsidian vault, especially `.obsidian/plugins` and `.obsidian/snippets`.
2. Export or copy Zotero's current highlight note template value.
3. Copy the Zotero profile's `chrome/userChrome.css` file.
4. Record Zotero advanced preference `toolkit.legacyUserProfileCustomizations.stylesheets=true`.
5. Back up ZotLit Template Workbench paper-note and annotation templates before editing.
6. Record installed plugin versions and any Zotero Style custom column definitions.
7. On the new machine, install Zotero and Obsidian, restore settings, and verify with a single PDF highlight drag.
8. Confirm that PDF deep links open the intended page and annotation.

Avoid publishing Zotero database files, private vault content, sync credentials or personal annotation exports.
